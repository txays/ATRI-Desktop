# ATRI · My Dear Desktop 使用说明

适用：Windows 10 / 11 64 位。此发行版包含 Electron、Live2D 模型及衣装资源，不需要安装 Node.js、Python、DeepSeek Harness 或 QQ 机器人。其他系统暂未提供可执行包。

## 1. 第一次使用

1. 下载名称类似 `ATRI-Desktop-v3.1.0-windows-x64.zip` 的安装包。
2. 右键压缩包 → 全部解压，将整个 `ATRI` 文件夹放到自己方便的位置，例如 `D:\Apps\ATRI`。不要在压缩包内直接双击程序。
3. 双击 `ATRI.exe`。也可使用 `Start-ATRI.cmd`；它会清理可能影响 Electron 启动的环境变量。
4. ATRI 出现在桌面，通知区域出现图标。首次启动会打开聊天设置；暂时关闭设置也能使用外观、互动、表情和衣橱。
5. 拖动人物移动位置；右键人物或托盘图标打开菜单。

程序没有购买代码签名证书，Windows 可能显示未知发布者。先核对下载来源与 SHA-256；如果杀毒软件明确报告威胁，请停止运行并向维护者反馈，不要关闭系统防护。

## 2. 日常操作

| 操作 | 方法 |
| --- | --- |
| 移动 | 按住人物拖动；透明区域通常点击穿透 |
| 聊天 | 右键 → 和 ATRI 聊天 |
| 设置自己的模型 | 右键 → 聊天与联动设置 |
| 换装 | 右键 → 衣橱与外观 → 打开衣橱 |
| 面部表情 | 右键菜单内的表情入口；含微笑、眨眼、害羞、不满、思考、惊讶 |
| 基础互动 | 右键菜单内摸头、戳、眨眼、跳跃等当前快照已有选项 |
| 调整大小 | 右键 → 调整大小 |
| 找回人物 | 托盘右键 → 回到右下角；显示 / 隐藏可恢复被隐藏的角色 |
| 专注模式 | 右键开关；兼容后端支持主动消息时，用于减少主动打扰 |
| 退出 | 右键人物或托盘 → 退出 |

本包保留发布快照中的原有身体、动作和渲染，没有安装其他任务中尚未完成的动作改动。可用功能以本版本菜单为准。

衣橱包含海盐奶油茶会、冬港来信、星潮航海师、绯雪星铃、白浪假日、经典水手服、居家睡裙、睡衣与南瓜裤。围巾、披肩和鞋履可以单独选择；穿搭和大小会自动保存。

## 3. 配置 AI 聊天

右键 → 聊天与联动设置，填写自己的服务并保存。保存后即可聊天，独立模式无需重启。

| 服务 | API 地址示例 | 模型示例 | 密钥 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 使用自己的 API Key |
| OpenAI | `https://api.openai.com/v1` | 填写账号可用且支持 Chat Completions 的模型名 | 使用自己的 API Key |
| 其他兼容服务 | 服务商提供的 `/v1` 基础地址 | 服务商给出的准确模型名 | 使用自己的 API Key |
| 本机 Ollama | `http://127.0.0.1:11434/v1` | 已下载的模型名 | 通常可留空 |

接口必须兼容 OpenAI Chat Completions；程序会在基础地址后追加 `/chat/completions`。只支持其他协议的接口需要自行使用兼容网关。远程地址要求 HTTPS；本机服务可以使用 HTTP。

API 消耗和费用由你自己的服务商结算。只有主动发送聊天时才请求模型；外观和衣橱不调用聊天 API。聊天会将本次文字、设定的人格和最近最多 30 条历史发送给所配置的服务。

密钥在当前 Windows 用户下通过系统凭据加密保存，设置页面不会回显。留空保留旧密钥；填写新值替换；勾选“删除已保存的密钥”清除。不要将个人数据目录分享出去。

## 4. 语音与 QQ / DSH 联动

独立便携版开箱提供文字聊天。ATRI 专属语音模型体积较大且有单独的资源使用条件，本包不包含 GPT-SoVITS 引擎、训练权重、参考录音、QQ 登录态或制作者的机器人账号。

已经自行部署兼容桌宠桥的用户，可在设置里展开“已有 QQ / DSH 后端的联动设置”，填写**自己后端生成的本机 `host.json` 完整路径**，保存并重启。发现文件须包含 `baseUrl`、`token` 和可选 `api`；地址只接受本机 `127.0.0.1`，令牌要求 32–80 位十六进制。桌宠沿用已有桥的聊天、语音和消息协议，具体能力取决于自己的后端版本。

普通用户保持此项为空。清空后保存并重启，即回到独立聊天。程序不会自动连接原制作者的 QQ 账号或读取本机其他项目配置。此发行中心不提供 QQ 后端部署器，完整 QQ 机器人功能需要单独部署和配置。

## 5. 升级、旧版和个人数据

发行中心和 GitHub Releases（启用后）按 `v版本号` 分别保存各个版本。下载新版后解压到**新文件夹**，先退出旧版，再启动新版。不要覆盖正在运行的程序。

设置与聊天记录保存在 `%LOCALAPPDATA%\ATRI Desktop`，不在安装目录内。因此更换文件夹或升级仍会读取原设置。当前保留最近 200 条独立聊天记录；日志和历史不随发行包分发。

需要回退时，退出新版，再启动旧版。未来版本如升级数据格式，应以该版本更新说明为准；升级前可备份个人数据目录。Windows 加密密钥不能直接搬到另一个用户或另一台电脑使用，迁移后请重新填写 API Key。

删除聊天记录：设置 → 清空独立聊天记录，之后关闭并重开聊天窗口以刷新显示。删除程序：先退出，删除解压文件夹。彻底清除个人数据时，再删除 `%LOCALAPPDATA%\ATRI Desktop`；这一操作会删除配置和独立聊天记录。

## 6. 常见问题

- **没有角色或角色在屏幕外**：先查看托盘，使用“显示 / 隐藏”和“回到右下角”。确认整个文件夹已解压，不要只复制 EXE。
- **双击没有反应**：同一用户默认只运行一个发行版实例，先从托盘退出旧版；尝试 `Start-ATRI.cmd`。这不会退出制作者原本正在使用的开发版。
- **角色黑屏或 Live2D 加载失败**：不要移动、删除 `resources`、`locales`、DLL 和模型文件，重新完整解压。检查显卡驱动；必要时从终端运行 `ATRI.exe --disable-gpu`。不同显卡组合仍需实际测试。
- **提示先填写设置**：这表示独立后端运行正常，但还没有可用的模型配置。填写自己的 API 服务、模型和密钥。
- **HTTP 401/403**：核对密钥和权限；**404**：核对基础地址及模型；**429**：检查额度或服务限流。程序不自动反复重试扣费请求。
- **连接失败或超时**：检查服务网络和地址。若使用本机模型，先启动 Ollama 并下载对应模型。
- **语音只有文字**：独立版没有内置专属语音引擎。需要自行配置兼容语音后端，或继续使用文字聊天。
- **联动显示离线**：先启动自己的后端，核对 `host.json` 路径和后端协议，再重启桌宠。
- **需要反馈问题**：提供版本、Windows 版本、复现步骤、提示文字和必要截图。不要发送 API Key、`connection.json`、`host.json` 或私人聊天记录。

## 7. 下载校验与素材说明

在 PowerShell 运行 `Get-FileHash -LiteralPath '.\ATRI-Desktop-v3.1.0-windows-x64.zip' -Algorithm SHA256`，将结果与对应版本的 `SHA256SUMS.txt` 比较。校验值相同只能证明文件与发布记录一致，不能替代对发布来源的信任。
