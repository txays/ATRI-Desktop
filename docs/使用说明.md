# ATRI 桌宠 v3.2.0 使用说明

**本 ATRI 桌宠只能绑定 QQ 聊天机器人 ATRI 账号 2635533699。** 你使用自己的 QQ 与它私聊，绑定你自己的桌宠；无需搭建另一个机器人。更换机器人或服务地址必须取得管理员签名批准，普通用户不能自行更改。

## 1. 下载和启动

适用 Windows 10 / 11 x64。从 [GitHub Releases](https://github.com/txays/ATRI-Desktop/releases/latest) 下载 `ATRI-Desktop-v3.2.0-windows-x64.zip`，右键 →「全部解压」，将整个 ATRI 文件夹放到方便的位置。

双击 `ATRI.exe`，或双击 `Start-ATRI.cmd` 启动并打开绑定窗口。不要在压缩包内运行，也不要只复制 EXE；`resources`、DLL、`locales` 与模型文件都必须保留。无需另装 Python、Node.js、DSH 或 QQ 机器人。

程序尚未购买代码签名证书。遇到未知发布者提示时，先核对发布来源和 SHA-256；如果安全软件明确报告威胁，请停止并反馈，不要关闭系统防护。

## 2. 绑定自己的 QQ

1. 添加 QQ 机器人 **ATRI：2635533699** 为好友。
2. 打开桌宠右键菜单 →「QQ 绑定…」。首次启动通常会自动打开。
3. 窗口中机器人是 **2635533699**，联动服务由管理员预置，地址为只读。
4. 点击「生成一次性绑定码」。绑定码有效期为五分钟，不要转发给别人。
5. 在**自己的 QQ 私聊 2635533699**，发送 `绑定桌宠 绑定码`，把最后三个字换成窗口生成的实际代码。
6. 回到桌面，核对窗口显示的是**你本人的 QQ 号码**，点击「确认绑定到 QQ …」。QQ 认领后仍需要这一步桌面确认。
7. 绑定成功后，用 QQ 发送 `你现在跳一下`、`眨眨眼` 或 `桌宠状态`。

每个 QQ 同时绑定一个桌宠。重新确认绑定会替换该 QQ 的旧桌宠绑定，旧令牌失效；其他人的桌宠不会受到影响。群聊不接受桌宠控制。

此版不提供独立聊天 API 设置。没有绑定、绑定已解除或服务离线时，聊天和 QQ 联动不能使用；人物显示、基础本地互动和衣橱可以先使用。

## 3. 日常操作

| 功能 | 方法 |
| --- | --- |
| 移动角色 | 按住人物拖动，透明区域通常点击穿透 |
| 桌面聊天 | 右键 →「和 ATRI 聊天」，使用自己绑定的 QQ 会话 |
| 查看绑定 | 右键 →「QQ 绑定…」 |
| 换装 | 右键 →「衣橱与外观」→「打开衣橱」 |
| 表情与本地互动 | 使用右键菜单内的微笑、眨眼、害羞、摸头、戳、跳跃等选项 |
| 调整大小 | 右键 →「调整大小」 |
| 找回角色 | 托盘右键 →「显示 / 隐藏」或「回到右下角」 |
| 退出 | 右键人物或托盘 →「退出」 |

衣橱保留八套现有衣装：海盐奶油茶会、冬港来信、星潮航海师、绯雪星铃、白浪假日、经典水手服、居家睡裙、睡衣与南瓜裤。支持配饰与鞋履选择，穿搭和大小会保存。

已绑定的用户可以私聊 **2635533699**：

| QQ 消息 | 用途 |
| --- | --- |
| `你现在跳一下`、`眨眨眼`、`摸摸头`、`戳一下你` | 控制自己桌面的基础动作 |
| `换上冬港来信`、`换上海盐奶油茶会` | 换整套衣装 |
| `戴上红围巾`、`摘掉围巾`、`打开衣橱` | 控制配饰或衣橱 |
| `桌宠状态`、`桌面互动`、`桌宠帮助` | 查询自己的状态、近期互动和帮助 |
| `解绑桌宠` | 撤销自己当前的桌宠绑定 |

以本版菜单和机器人帮助为准。服务端可能识别更多动作名称；客户端没有该动作时会返回明确失败，不能保证所有扩展动作均支持。

桌面摸头、拖动、换装等互动会加入你后续 QQ 对话的上下文；QQ 中自己的消息及实际发送成功的回复可以同步到桌面。桌面输入只回复桌面。语音取决于 ATRI 后端的当前可用状态，此包不包含本地专属音色引擎或训练权重。

## 4. 账号限制与服务依赖

此版本只允许连接管理员批准的 ATRI QQ **2635533699**。客户端验证管理员签名，并检查绑定与聊天服务返回的机器人身份。手改账号、地址、环境变量或添加“已批准”字段不能替代有效签名。

服务地址以绑定窗口内已签名的配置为准，当前为 `https://beta.u1842105.nyat.app:59148`。它由服务提供者运行；服务、机器人或隧道停机时，客户端会离线。证书异常应由服务提供者处理，不要关闭证书验证。

绑定和联网聊天会将必要的绑定请求、你主动发送的文字及桌面互动交给 ATRI 服务处理。客户端不包含服务提供者的 QQ 密码、登录态、模型密钥、管理员私钥或其他人的对话记录。

## 5. 解除绑定和更换电脑

在自己的 QQ 私聊机器人发送 `解绑桌宠`，或在桌宠绑定窗口点击「解除当前绑定」。解绑后旧凭据被撤销。

换电脑时下载原始 ZIP，在新电脑重新执行绑定流程。确认新绑定后，该 QQ 的旧桌宠绑定会被替换。不要把已运行的个人数据目录发给别人。

## 6. 升级与旧版处理

本次 **v3.2.0 替换 v3.1.0**，GitHub 旧版发布与标签此次移除。以后新版本可以按独立 Release 保留，使用固定的「下载最新版」链接即可获取最近版本。

先退出旧程序，再把新版解压到新目录启动。新发行版数据统一保存在 `%LOCALAPPDATA%\ATRI Desktop`；右键 →「打开个人数据目录」可以定位。旧独立版的 API 配置不再用于此版，首次需要 QQ 绑定。其他来源的旧 QQ 客户端可能把数据放在自身的 `desktop/data/userdata` 中，升级本发行版时请重新绑定。

Windows 加密凭据与当前用户关联，不能简单搬到别的电脑使用。备份目录可能含私人信息，不要公开。卸载时先退出并删除程序文件夹；若要撤销账号绑定，先执行解绑，再按需要删除个人数据。删除本地文件不能代替服务端解绑。

## 7. 常见问题

- **无法生成绑定码**：确认网络可访问窗口内的 HTTPS 服务。服务可能维护或离线，请联系提供者；不要随意替换地址。
- **QQ 不接受绑定**：确认发送对象是 **2635533699**、双方已是好友、使用私聊、绑定码没有过期。
- **QQ 已认领但桌面没有连接**：回到绑定窗口核对自己的 QQ，完成桌面确认。若已过期，重新生成。
- **显示“机器人身份不符”或“配置未经管理员批准”**：使用官方发布的完整新版包；更改账号或服务需要管理员签名，不要关闭校验。
- **旧客户端突然失去连接**：同一个 QQ 确认了新绑定后，旧绑定会被替换；只保留当前需要的桌宠运行。
- **QQ 提示桌宠离线**：确认程序正在运行，绑定的是本人的 QQ。尝试 `桌宠状态`，检查网络和服务状态。
- **角色不见了**：托盘右键「显示 / 隐藏」「回到右下角」，确认没有遗留运行实例。
- **黑屏或模型加载失败**：重新完整解压，检查显卡驱动；不要只移动 EXE。如需要，可从终端尝试 `ATRI.exe --disable-gpu`。
- **语音或普通聊天失败**：可能是机器人模型或语音服务暂不可用；基础本地互动仍可使用。明确动作也需要公网联动服务可连接。
- **反馈问题**：附版本、Windows 版本、复现步骤、错误文字和必要截图，隐藏自己的 QQ 与绑定码。不要上传 `qq-binding.json`、令牌、聊天记录或登录凭据。
